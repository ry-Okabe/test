PWA 音声入力テスト

プロフェッショナル診断のコメント欄・メモ帳の「音声入力」を想定。iPad(Safari)/Android(Chrome)、特にホーム画面に追加した standalone で「話した内容が文字になるか」を確認します。

音声認識 (Web Speech API)—
状態停止
認識結果
イベントログ（onstart / speechstart / result / onerror / onend）
※ Web Speech API は端末により音声データが外部（Google 等）へ送信されます（セキュリティ方針 L2 の論点）。
※ iOS 標準／スタンドアロン PWA では音声認識が途中で止まる／一度しか動かないことがあります。その場合、本番は「OS キーボードの音声入力（ディクテーション）」か「録音＋サーバー文字起こし」を前提にします。
