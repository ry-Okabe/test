PWA 音声入力テスト

プロフェッショナル診断のコメント欄・メモ帳の「音声入力」を想定。1タップ＝1セッション（毎回作り直し）で、2回目以降も結果が返るかを検証します。
表示モード—
音声認識 (Web Speech API)—
状態停止
認識結果
参考：OSキーボードの音声入力（本番で使える方法・何度でも動く）
※ Web Speech API と違い OS 機能なので、standalone でも制限なく使えます。本番の音声入力はこちらを前提にできます。
イベントログ（セッション番号付き）
※ iOS は「設定 → プライバシーとセキュリティ → 音声認識」を ON ＋ マイク許可が必要です。
※ 検証観点：2回目以降のセッションで onresult（結果）が来るか。来ない場合は「iOS では音声認識が実質1回しか結果を返さない」既知現象で、本番は OSキーボードの音声入力／録音＋サーバー文字起こしに倒します。
