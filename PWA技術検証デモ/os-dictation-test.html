OS音声入力（ディクテーション）テスト

キーボードのマイク🎤で入力する方式です（Web Speech API は使いません）。ホーム画面に追加した standalone でも、何度でも音声入力できることを確認します。
表示モード—
入力文字数0
最後の入力—
ここに音声入力（コメント欄・メモ帳の想定）
使い方
  1. iPhone / iPad：上のテキスト欄をタップ → キーボード下部のマイク🎤をタップ → 話す（もう一度マイクで停止）
  2. Android：テキスト欄をタップ → キーボード（Gboard等）のマイク🎤 → 話す
  3. 何度でも繰り返して追記できます。上の「入力文字数／最後の入力」が更新されれば動作OK
※ これは本番のコメント欄・メモ帳で採用予定の方式です。アプリ（本システム）側からは音声を外部送信しません（OSのディクテーション処理自体はOSに準じます）。
※ 画面上に独自の「🎤音声入力ボタン」は不要（キーボードに最初からマイクがあるため）。
